## 🚀 Proyecto destacado — Bodega Ecole

API REST para gestión de bodega, construida como proyecto principal donde aplico y consolido las tecnologías que aprendo. Desplegada en producción con arquitectura de tres capas independientes:

| Capa | Tecnología | Plataforma |
|------|------------|------------|
| **Backend** | NestJS + TypeScript, contenerizado con Docker | Render |
| **Frontend** | React | Vercel |
| **Base de datos** | MySQL | Aiven |

**Aplicado en el proyecto:**
- Arquitectura backend modular con NestJS y TypeScript
- Persistencia con MySQL vía TypeORM y migraciones versionadas con Flyway
- Contenerización con Docker para entornos reproducibles
- Despliegue con backend, frontend y base de datos desacoplados en servicios cloud independientes
- Control de versiones y flujo de trabajo con Git/GitHub
